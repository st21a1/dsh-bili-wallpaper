# 截图放这里

README 里引用了两张图，把真实截图按下面的文件名放进这个目录即可：

| 文件名 | 内容 | 建议 |
| --- | --- | --- |
| `screenshot-settings.png` | **设置 → B站背景** 整页 | 640px 宽，能看清五块（开启背景 / 来源 / 清晰度 / 画面 / 账号） |
| `screenshot-background.png` | 直播画面当背景的实际效果 | 640px 宽，让聊天窗口和半透明面板都出现在同一张图里 |

放好之后，把 `README.md` 里 `### 界面` 下面那段 <!-- --> 注释解开，README 就会显示这两张图。

> 提示：截图前先把 Profile 里的 B 站昵称、聊天内容里可能涉及隐私的部分遮掉再截。
